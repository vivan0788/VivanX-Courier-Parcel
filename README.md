🚚 VivanX Courier Parcel

«Fast. Safe. Reliable.»

A modern, responsive, and professional courier company website built using HTML5, CSS3, and Vanilla JavaScript. This project is completely static and does not require any backend or database.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/vivanx-courier.git

2. Open the project folder.

3. Open index.html in your browser.

No installation or build process is required.
